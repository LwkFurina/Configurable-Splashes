Configurable Splashes

This mod lets you change the text next to the Minecraft logo on the title screen.

Normally, that text changes randomly every time you open the game. With this mod, you pick your own text, and it stays the same every time.

What it does:

Change the title screen text to anything you want
Works alone, no other mods needed
Only changes your own game, not the server
How to use it:

Install the mod
Open the game once, this creates a small settings file
Open that file in a text editor
Type in your own text
Save and restart the game
That's it! your new text will show up on the title screen.
